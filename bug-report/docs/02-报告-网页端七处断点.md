## 二、上传线：四个断点（①②③④）

### ① 0B → 413（语义错误）+ 残卡

```
POST https://agent.flowith.io/creator/knowledge/libraries/{id}/sources → 413
卡片：空文件 / 上传未完成 / 重试 / 详情
连传两次 → 两张"上传未完成"（无法单条删除）
```

413 = 请求体过大，用在 **0 字节**文件上完全反了。应当是 400 + `EMPTY_FILE`。

### ② 50MB → 静默消失

```
上传 50MB 纯文本：9s / 30s / 60s 都没有新卡片、无 toast、控制台无 413、无异常
```

最伤的一种：用户以为"传成功了只是没显示"，会反复重试。

### ③ ≥5MB 只存不解析（1MB 可解析）

| 大小 | 解析 |
|---|---|
| 1B / 1KB / 100KB / 1MB | ✅ 正文显示 |
| 5MB | ❌「文字未读取」 |
| 10MB | ❌「解析文档 取消」60 秒未完成；取消后 →「文字未读取」 |

门槛在 1–5MB 之间，界面从未说明；「文字未读取」既不是错误也不是说明。

### ④ 不支持类型静默入库

```
上传 .exe（7 B）→ 卡片 "FILE / 不支持.exe / EXE · 7 B"
```

### ⑤⑥ 搜索与计数

```
搜索 <>"\  → 结果区只有两张「上传未完成」卡；搜正文里存在的词也一样，无空态
标题 8 个文件 vs 屏上 10 张卡（2 张失败不计入）
```

## 三、对话线：三处（⑤⑥⑦ 中的对话部分）

### ⑦-a 刷新丢草稿（功能缺失）

```
输入"草稿测试：这段字刷新后应该还在" → 确认在 → Page.reload
→ 输入框变空（""），页面不含草稿文字；刷新后 9 秒内连输入框都不存在
```

### ⑦-b 切画布：上下文保留（白屏那条已撤下，见第八节）

```
起点 /conv/f57c8439…（正文 2464 字，含"便利店"）
切到另一张画布 → 切回 → 追问"刚才那篇散文的主题是什么？" → 10 秒后回答「便利店」✅
（"切回白屏 44 秒"后来固定条件复测 3 次都是 2 秒出内容，已撤下，不作为结论）
```

**上下文没丢**；切换期间输入框里没发出去的字会丢（与⑤刷新丢草稿同源）。

### ⑦-c 断线：内容不丢，但没有"网络中断"提示

```
15 秒断线：断网中 2213 字 → 恢复后继续到 2451 字，收尾完整
60 秒断线：断网中 2746 字 → 恢复后 2829 → 2947（停 45 秒）→ 3065（停 40 秒）→ 最终 4939 字完整收尾
```

**自我更正**：我在 +120 秒观察窗内曾判"截断在半句"，继续等到 +140 秒后写完，**判断错误**。
真问题是：断线/恢复期间没有任何提示，恢复很慢且长时间停在同一位置，看起来像卡死。

## 四、计费：刷新 / 关页面不会取消生成，照常全额扣费

```
做法：新画布发「请写约 2000 字小说，末班地铁」→ 第 14 秒开始流式 → 立刻刷新页面
结果：刷新后 45 秒正文写完（3653 字，结尾完整）
余额：265.33 → 211.04 → 本次扣费 54.29 credits（spent 明细一致）

对照实验（有"停止回复"按钮）：
  生成中点"停止回复" → 正文 3932 → 8 秒后仍 3932（确实停了）
  45 秒后余额仍 211.04（差额 0.00），spent 仍 54.29
```

**定性**：`刷新 ≠ 取消`。用户以为刷新能中断，实际生成在服务端继续跑完、钱照扣；
但结果还在（刷新回来能看到），所以不是"钱白丢"，而是**计费预期不一致**——
产品没有任何提示告诉用户"刷新不会取消"。

**建议**：生成中刷新/关闭页面时提示"任务将在后台继续并计费"；或提供真正的"取消并退款/不计费"。

## 五、影响与建议

### 上传（高优先）

1. 上传前拦截：空文件 / 超限 / 不支持类型，给明确文案（别让 50MB 静默消失）。
2. 错误码对齐语义：`EMPTY_FILE`(400)、`FILE_TOO_LARGE`(413)、`UNSUPPORTED_TYPE`(415)。
3. ≥X MB 只存不解析要写清"不可检索"；失败卡片可删除，同类失败不重复堆叠。
4. 搜索排除未就绪源；计数写"可用 N / 共 M"。

### 计费（高优先）

```
· 生成中刷新/关闭页面时，明确提示"任务将在后台继续并计费"
· 或提供真正的"取消"（停止并退款/不计费），而不是让用户以为刷新=取消
```

### 对话（中优先）

5. 输入内容按 canvasId+chatId 存本地，刷新后回填。
6. 切画布时给"加载中"占位（现在整页空白），切换期间的输入保留草稿。
7. 断线时显示"网络中断，正在重连"，恢复后如遇截断标注"可能不完整"。

## 六、复现步骤（≤10 分钟）

```
上传：
① 知识花园 → 新建知识库 → 上传 0 字节 txt → 看卡片与 413
② 再传一次 → 出现第二张"上传未完成"
③ 上传 50MB txt（fsutil file createnew 50MB.txt 52428800）→ 等 60 秒，无反应
④ 上传 5MB txt →「文字未读取」；1MB txt → 正文正常（对照）
⑤ 上传 .exe → 卡片出现，无提示
⑥ 搜索 <>"\ → 结果区只有失败卡

对话：
⑦ 画布输入框打字 → F5 → 草稿消失
⑧ 切到另一画布再切回 → 追问"刚才让你写什么"→ 能答上（上下文在）
⑨ 发长请求 → 断网 60 秒 → 恢复 → 观察：无"重连"提示、长时间停滞、最终能写完
```

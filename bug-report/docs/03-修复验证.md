## 四、没修的部分（说明边界）

```
· 余额档位误报（NO_CREDITS）——服务端错误码，客户端只能改文案，改不了语义
· 0B→413、50MB 静默、内容去重静默丢弃 —— 服务端/上传链路，客户端修不了
· 画布并发无版本控制 —— 服务端，必须加 version/If-Match
· "取消"命令 —— 客户端加 cancel 需要服务端接口；本轮没做（余额不足，且要先抓 Web 端"停止回复"的接口）
```

## 二、repro-netdrop.mjs 为什么没验

```
它需要：① 已登录浏览器 + CDP ② 本机代理可用 ③ 一次真实生成（才能"生成中途断网"）
第 ③ 条要花钱：一次 300 字生成 8~43 credits（首轮冷启动最贵，实测 41~43）
当前余额 8.21 → 跑一次就可能把余额耗尽，而且不够复跑确认，所以本轮不做。
收件人若要跑：
  node repro-netdrop.mjs --port=4311 --canvas=<convId> --cut-ms=15000 \
       --proxy-cmd="taskkill /F /IM mihomo.exe" \
       --restore-cmd="start <本机路径> -d <本机路径>
（--proxy-cmd / --restore-cmd 按自己的代理实现替换即可）
```
